# 《老友记》3D 等轴测微缩岛 (Friends 3D Voxel Diorama)

一个打开就能沉浸其中的《老友记》3D 微缩交互孤岛。严格根据实物 DIY 微缩模型比例 1:1 体素级手工还原。

---

## 🌟 核心场景与空间结构

### 1. ☕ Central Perk 咖啡馆微缩岛
- **标志性橘色大沙发与绿地毯**：经典六人组围坐
- **咖啡吧台与特浓咖啡机**：Gunther 吧台守候，冒着微缩袅袅蒸汽
- **Phoebe 演出小舞台**：麦克风支架、复古木吉他、暗红绒布幕帘
- **窗边高脚桌椅与暖黄壁灯**

### 2. 🏢 4 楼一体化双公寓微缩岛 (4th Floor NYC Apartments)
通过左上角 `[🏢 去 4楼双公寓]` 一键触发 360° 旋转变焦无缝切换！
- **左侧：Joey & Chandler 的单身汉公寓 (Apt 19)**
  - 🛋️ **灵魂皮躺椅 (Barcaloungers)**：Joey 与 Chandler 的最爱，点击可触发经典音效
  - 🛶 **客厅独木舟 (The Canoe)**：被盗后的经典独木舟与两支木桨
  - ⚽ **桌上足球台 (Foosball Table)**：绿茵草坪、球门、四根镀铬操纵杆与黄蓝小球员
  - 🦆🐥 **The Chick & The Duck**：电视柜旁的小鸡和小鸭
  - 🐶 **Pat the Dog 陶瓷大白狗雕像**：配有独立射灯照射
  - 🧲 **19 号门后磁力画板 (Magna Doodle)**：手绘经典老友记彩蛋
  - 🛋️ **黄色小沙发与 Hugsy 企鹅玩偶**
  - 🍳 **L 型早餐吧台与高脚圆凳**、双开门大冰箱、复古燃气灶
- **中间：4 楼连廊与楼梯间 (The Central Hallway)**
  - 门对门设计：左侧 19 号门，右侧 20 号门（均配有 3D 黄铜门牌号）
  - 复古木制楼梯转角扶手、欧式墙壁复古壁灯
  - 🍰 **地上的芝士蛋糕彩蛋**：Mama's Little Bakery 芝士蛋糕，点击触发偷吃名场面！
- **右侧：Monica & Rachel 的紫门大公寓 (Apt 20)**
  - 🚪 **经典紫色大门与黄色猫眼相框**
  - 🍳 **蓝色复古开放式厨房**、中央大圆餐桌与各色混搭餐椅
  - 🪟 **黑色大格子落地飘窗**与碎花窗帘
  - 🛋️ **白色布艺沙发与手工拼接地毯**
  - 🛁 **卫生间里 Chandler 的泡澡小黄鸭**

## 🎮 精彩小剧场与交互

- **小剧场导演模式**：
  - ☕ 咖啡馆：争论“冷静期”、Phoebe 唱臭臭猫、Joey 盯着蛋糕、Rachel 端咖啡、PIVOT 搬沙发、龙虾灵魂伴侣
  - 🏢 4楼公寓：Joey & Chandler 桌上足球大战、4楼过道偷吃芝士蛋糕、客厅皮划艇划水、Monica 火鸡头舞、抢房闪电竞猜、窗前围观裸男、Monica 洁癖大扫除
- **3D 视角自由运镜与预设机位**：
  - 🏢 4楼全景 / 咖啡馆中景
  - 🐥 Joey 家特写 (躺椅与独木舟) / 🛋️ 沙发六人组
  - 🚪 Monica 家特写 (紫门与厨房) / ☕ 吧台特写
  - 🍰 4楼过道特写 (芝士蛋糕) / 🎸 Phoebe 演出角
- **声音系统**：
  - Web Audio API 合成音效：桌上足球拨杆乒乓声、芝士蛋糕银叉碰撞声、白狗汪汪声、皮划艇划水声、咖啡蒸汽嗤嗤声、宝丽来机械快门声
  - 真实角色英文 TTS 配音与多轮对话引擎
- **宝丽来复古拍立得相机**：一键生成带老友签名与纸胶带的复古拍立得卡片并可下载。

## 🚀 运行方法

在当前文件夹下启动静态 HTTP 服务：
```bash
python3 -m http.server 8080
```
然后在浏览器访问：`http://localhost:8080`
